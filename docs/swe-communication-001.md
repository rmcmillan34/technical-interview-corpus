# SWE communication coverage audit 001

The current SWE coverage validator shows no D1, D2 or D3 advisory for core `communication`.

Communication is already exercised as a primary or secondary competency across explanation, coding, debugging, behavioural and system-design questions. Adding new questions solely to satisfy a per-competency tranche would duplicate existing assessment value and distort the corpus.

This pass therefore records an explicit no-add decision. Future communication questions remain welcome when they assess a distinct behaviour, modality, audience or engineering context rather than merely increasing count.
