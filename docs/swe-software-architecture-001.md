# SWE software architecture coverage slice 001

Completes the current D1/D2/D3 planning floors for core `software-architecture`.

The slice covers coupling/cohesion, separation of concerns, monolith versus microservices and dependency boundaries at D1; bounded decomposition and integration choices at D2; and staged service extraction plus provider-adapter architecture at D3.

Secondary classifications deliberately capture real distributed-systems, reliability, delivery and technical-judgement evidence rather than duplicating separate questions.
